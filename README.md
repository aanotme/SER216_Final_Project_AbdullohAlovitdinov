# Digital Parking Permit System

## Functional Requirements

1. Students and staff can register vehicles

2. Request parking permits

3. Check available parking zones

4. Report parking issues

## Non-functional Requirements

1. Parking system should work without any interruptions - 24/
2. A reliable and fast coding language supposed to be used to make it as fast as possible

* 2 system test cases

system meets user or business expectations.
